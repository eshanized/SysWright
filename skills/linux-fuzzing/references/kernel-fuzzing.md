# Linux Kernel Fuzzing: syzkaller, KCOV, and VM Sandboxing

Technical reference for coverage-guided kernel fuzzing using Google's syzkaller, KCOV, and QEMU isolation.

---

## 1. syzkaller Architecture

`syzkaller` is an unsupervised, coverage-guided kernel fuzzer that tests the Linux kernel boundary through system call descriptions:

```
[syz-manager (Host Controller)] 
      │
      ├── (Spawns & Monitors via SSH) ──► [QEMU VM 1] ──► [syz-fuzzer] ──► [Kernel under test (KCOV)]
      │
      └── (Spawns & Monitors via SSH) ──► [QEMU VM 2] ──► [syz-fuzzer] ──► [Kernel under test (KCOV)]
```

### Components:
- **`syz-manager`**: Runs on the host; manages VM pool, persists crash artifacts, and generates HTML status dashboards.
- **`syz-fuzzer`**: Runs inside the guest VM; executes test programs generated by mutation.
- **`syz-executor`**: Small C++ binary that executes a concrete sequence of system calls.
- **`syz-lang`**: Declarative language describing system call interfaces, struct layouts, and argument constraints.

## 2. Kernel Configuration Requirements for Fuzzing

A kernel must be compiled with specific debugging and instrumentation options to enable syzkaller fuzzing:

```ini
# Kernel Code Coverage (KCOV) support via /sys/kernel/debug/kcov
CONFIG_KCOV=y
CONFIG_KCOV_INSTRUMENT_ALL=y
CONFIG_KCOV_ENABLE_COMPARISONS=y

# Sanitizers
CONFIG_KASAN=y
CONFIG_KASAN_INLINE=y
CONFIG_UBSAN=y
CONFIG_FAULT_INJECTION=y
CONFIG_LOCKDEP=y

# Debugging information
CONFIG_DEBUG_INFO=y
CONFIG_DEBUG_INFO_DWARF4=y

# Virtualization / Network support for VM boot
CONFIG_VIRTIO_NET=y
CONFIG_VIRTIO_PCI=y
CONFIG_NET_9P=y
CONFIG_9P_FS=y
```

---

## 3. Mandatory Isolation Rule

> [!CAUTION]
> **NEVER execute kernel fuzzing on bare metal or on the host development machine.**
> Kernel fuzzing routinely triggers kernel panics, memory corruption, and disk I/O faults. Fuzzing on the host OS can corrupt root filesystems, destroy partition tables, or render the host unbootable.
> **Rule**: Kernel fuzzing must strictly run inside isolated QEMU/KVM virtual machines with snapshot/ephemeral copy-on-write disks (`-snapshot`).
